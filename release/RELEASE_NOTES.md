## PlutoDocs 0.1.0

A modern rich-text document processor for Windows, part of the Pluto software suite.

### Downloads

| File | Use it when | Size |
| --- | --- | --- |
| `PlutoDocs_0.1.0_x64-setup.exe` | **Recommended.** Standard installer with Start menu shortcut and `.pluto` file association | 1.9 MB |
| `PlutoDocs_0.1.0_x64_en-US.msi` | Deploying with Group Policy, Intune or other MSI tooling | 2.6 MB |
| `PlutoDocs_0.1.0_x64_portable.exe` | Running without installing (keeps its data in a `PlutoDocs Data` folder next to the exe) | 5.0 MB |
| `PlutoDocs_0.1.0_x64_portable.zip` | Same portable build, zipped with its `portable` marker file for USB drives | 2.3 MB |

Requires Windows 10 or 11 (64-bit) with the Microsoft Edge WebView2 runtime, which is built into Windows 11. The installers set it up automatically if it is missing.

> The binaries are not code-signed yet, so Windows SmartScreen may show "Windows protected your PC". Choose **More info → Run anyway**.
